# FER2013 source folders

Keep raw images local or in approved private storage. The configured source is KaggleHub dataset `msambare/fer2013/versions/1`, saved under `data/fer2013/` with `train/` and `test/` folders. The data command writes the split manifest to ignored `outputs/data/`.

Check dataset access terms before use. Do not commit raw images, Kaggle credentials, or private manifests.
